# 01 产品需求文档（PRD）

## 1. 产品概述

CodeTree 面向编程初学者和需要移动实践的进阶学习者，通过可关联的知识树、词典、双语示例、终端和 AI 助手，降低「知道名词但不会应用」和「遇到错误不知道下一步」的学习成本。

### 1.1 产品原则

- **先形成闭环，再扩展广度**：一个知识节点必须能连接术语、示例和实践。
- **离线优先**：已下载内容不依赖网络，AI 和远程下载是明确的在线能力。
- **解释优于堆叠**：界面优先呈现下一步，不同时展示所有高级功能。
- **实践必须安全**：终端和插件不能因学习操作破坏用户数据或系统。
- **AI 是辅助而非权威**：代码执行、测试和引用内容与生成回答分开呈现。

### 1.2 非目标

首版不做完整桌面 IDE、完整 Linux 发行版、无限制任意代码执行、公开插件市场、多人协作、社交社区、账号云同步和付费系统。

## 2. 用户与核心场景

| 用户 | 主要问题 | 核心场景 |
| --- | --- | --- |
| 零基础学习者 | 不知道学习顺序，英文术语难以理解 | 从引导路径进入概念，查看中文解释与双语示例，运行安全练习 |
| 有基础的学习者 | 知识分散，遗忘语法和术语 | 模糊搜索术语，跳转相关知识，按需下载语言包 |
| 移动实践用户 | 缺少随时运行和排错的环境 | 在终端编辑命令或短代码，获得诊断、补全和 AI 错误解释 |
| 内容/插件作者 | 希望扩展课程和语言支持 | 按清单规范制作声明式内容包，导入并验证依赖 |

### 2.1 核心用户旅程

1. 用户完成三页引导并选择学习方向。
2. 首页展示当前路径和下一节点，而非空白仪表盘。
3. 用户打开节点，查看目标、解释、术语和双语代码。
4. 点击代码中的术语进入词典，再返回原学习位置。
5. 在终端运行预置安全示例，看到高亮、诊断和输出。
6. 用户主动选择「询问 AI」，确认将发送的代码或错误上下文。
7. 返回节点完成练习，更新进度并解锁后续建议。

## 3. 信息架构

底部导航固定为五项：

| 入口 | 一级页面 | 二级能力 |
| --- | --- | --- |
| 学习 | 当前路径、知识树、分类目录 | 节点详情、练习、关联术语、进度 |
| 词典 | 搜索、历史、收藏 | 术语详情、双语语法、相关知识节点 |
| 终端 | 会话、文件、输出 | 补全、诊断、运行时选择、AI 排错 |
| AI | 对话、上下文选择 | 模型设置、请求状态、历史会话 |
| 我的 | 知识包、插件、学习记录、设置 | 存储管理、隐私、安全与关于 |

## 4. 功能需求

优先级：P0 为首个可验收 MVP，P1 为随后版本，P2 为长期扩展。

### 4.1 学习知识树（LRN）

| 编号 | 优先级 | 需求 | 验收摘要 |
| --- | --- | --- | --- |
| LRN-001 | P0 | 图谱采用云图扩散布局，支持缩放、拖动、节点选择和回到当前位置 | 同数据与选中状态重复进入时布局稳定；节点密集时仍可操作；选中节点与详情状态一致 |
| LRN-002 | P0 | 边类型包含前置、相关、应用和易混淆 | 不同关系有文字/图例，不仅依赖颜色区分 |
| LRN-003 | P0 | 节点详情包含目标、讲解、示例、术语、练习和关联节点 | 内容缺失有明确状态，不展示空白区块 |
| LRN-004 | P0 | 学习状态为未学、学习中、已掌握 | 状态本地持久化，重启后保持 |
| LRN-005 | P0 | 从术语、练习和 AI 上下文可回到对应知识节点 | 返回后保留原学习位置和滚动状态 |
| LRN-006 | P1 | 根据前置关系生成学习路径 | 不形成死循环；缺失前置有解释 |
| LRN-007 | P1 | 支持路径筛选和学习目标筛选 | 筛选结果与图谱、列表一致 |

首批知识域：编程基础、计算思维、Git、Python、JavaScript、Kotlin、Android、Web、数据结构、网络基础、AI 基础和 Vibe Coding。Vibe Coding 内容至少覆盖需求描述、上下文组织、迭代提示、代码审查、测试验证、调试、版本控制和安全边界，不能只讲提示词。

### 4.2 词典与双语语法（DIC）

| 编号 | 优先级 | 需求 | 验收摘要 |
| --- | --- | --- | --- |
| DIC-001 | P0 | 支持中文、英文、缩写和别名检索 | 同一术语的别名不会生成重复详情页 |
| DIC-002 | P0 | 离线全文搜索与结果排序 | 精确匹配优先于前缀，前缀优先于模糊匹配 |
| DIC-003 | P0 | 无精确结果时提供模糊建议 | 显示建议原因，不把低相关结果冒充精确答案 |
| DIC-004 | P0 | 详情含定义、语法、示例、常见错误、相关术语和知识节点 | 各关联跳转可用，内容版本可追踪 |
| DIC-005 | P0 | 中文解释、英文语法、双语对照三种模式 | 模式选择被记住；代码不被翻译破坏 |
| DIC-006 | P1 | 搜索历史与收藏 | 可单条删除和清空，默认仅本地保存 |
| DIC-007 | P1 | 可选拼音和首字母检索 | 不影响英文精确结果排序 |

### 4.3 终端（TRM）

| 编号 | 优先级 | 需求 | 验收摘要 |
| --- | --- | --- | --- |
| TRM-001 | P0 | 终端会话支持输入、输出、错误、清屏和历史 | 长输出不阻塞界面，进程结束后状态明确 |
| TRM-002 | P0 | 内置安全命令和应用私有文件沙箱 | 路径穿越和越权访问被拒绝并给出原因 |
| TRM-003 | P0 | 实时代码高亮、括号匹配和错误下划线 | 编辑普通长度示例时无明显输入阻塞 |
| TRM-004 | P0 | 诊断包含位置、原因和可选修复 | 修复前后差异可预览，不静默改代码 |
| TRM-005 | P0 | 上下文感知的模糊补全 | 接受建议后光标位置正确，不覆盖后续文本 |
| TRM-006 | P0 | 所有执行具有超时、输出和资源限制 | 超限可终止并恢复新会话 |
| TRM-007 | P1 | 统一运行时接口，接入 Python/JavaScript | 运行时可安装、缺失、卸载和失败恢复 |
| TRM-008 | P2 | Termux 或完整 Linux 适配 | 独立安全评估，不与 P0 终端混为同一能力 |

### 4.4 AI 助手（AIA）

| 编号 | 优先级 | 需求 | 验收摘要 |
| --- | --- | --- | --- |
| AIA-001 | P0 | 可配置 Base URL、模型和密钥，抽象 Provider | 不硬编码供应商地址；无配置时进入引导而非报错 |
| AIA-002 | P0 | 流式回答、取消、重试和完整错误状态 | 取消后不再追加输出；重试不重复发送不知情请求 |
| AIA-003 | P0 | 可引用当前节点、术语、代码和终端错误 | 发送前展示上下文，默认不自动附带敏感内容 |
| AIA-004 | P0 | 本地保存会话，支持删除 | 密钥不出现在消息、日志或导出文件中 |
| AIA-005 | P0 | 明确区分 AI 建议与实际执行结果 | 「运行」和「验证」由终端/测试产生，不由模型声明 |
| AIA-006 | P1 | 用量、超时、网络与速率限制提示 | 错误可理解且提供下一步，不泄露响应头秘密 |
| AIA-007 | P1 | 可选后端代理模式 | 客户端无需内置统一商业密钥 |

## 5. 非功能需求（NFR）

| 编号 | 目标 |
| --- | --- |
| NFR-001 | 最低支持 Android 8.0（API 26）；目标 SDK 在工程初始化时按当时稳定版本确认并记录 |
| NFR-002 | 10,000 条本地术语下，搜索响应目标 P95 小于 300ms，测试数据与设备需记录 |
| NFR-003 | 下载和安装失败不破坏既有可用知识包；数据库升级必须可迁移 |
| NFR-004 | 仅申请必要权限；首版不请求全盘文件访问、通讯录、位置或麦克风权限 |
| NFR-005 | AI 密钥使用平台安全能力保护；日志、崩溃报告和测试快照不得包含密钥 |
| NFR-006 | 核心学习流程在无网络、无账号情况下可用 |
| NFR-007 | 所有面向用户的错误均提供原因和下一步，技术细节不暴露敏感信息 |

## 6. 内容原则

- 中文解释准确、简洁，英文保留原始关键字和官方术语。
- 示例必须标注语言、适用版本、预期输出和是否需要运行时。
- 每个示例由内容作者和至少一名审查者核对；可执行示例应进入自动测试。
- 知识节点和术语使用稳定 ID，显示名称可修改，关联不依赖名称。
- AI 生成内容只能作为草稿，进入内置知识库前必须经过人工或独立审查流程。

## 7. MVP 完成标准

MVP 不只是五个页面可打开，而是至少一条学习路径在真实设备上完成端到端验收：下载内容包 → 离线打开知识树 → 查询关联术语 → 阅读双语示例 → 在安全终端执行 → 主动请求 AI 解释或验证未配置状态 → 返回并保存学习进度。所有 P0 安全测试和发布门禁必须通过。
