# 11 宣传设计规范

> 本规范约束「编程猫」在应用商店、社交媒体、发布会、开屏、海报和分享卡片上的视觉表达。它不替代产品界面规范；应用内视觉以 `docs/09-VISUAL-DESIGN.md` 为准。

## 1. 目标与受众

| 项目 | 决策 |
| --- | --- |
| 宣传目标 | 让目标用户在三秒内记住「编程猫」、知道它解决什么问题、愿意点开或下载 |
| 首要受众 | 零基础与转行的编程初学者，尤其是被术语、英文和报错卡住的人 |
| 次要受众 | 需要移动碎片时间实践的进阶学习者、内容创作者、教育机构 |
| 核心承诺 | 把知识养成立体的树，让概念、术语、示例和练习连起来 |
| 语气 | 好奇、轻快、可靠；不制造焦虑，不承诺速成 |
| 主口号 | 把知识，养成一棵树 |
| 备选口号 | 一只猫，陪你把代码读懂 / 从名词到会用，只差一棵树 |

宣传不把「AI」作为唯一卖点。AI 是学习闭环的一环，首版更重要的差异是**知识树 + 双语示例 + 安全终端**的组合。

## 2. 信息层级

每张宣传物只保留一个主信息，最多三个支撑点：

1. **品牌名**：编程猫 / CODECAT。
2. **主标题**：一句具体收益，不超过 12 个汉字。
3. **副标题**：说明怎么做到，不超过 24 个汉字。
4. **支撑点**：三个短标签，每个不超过 8 个汉字。
5. **行动入口**：二维码、应用商店徽标或「搜索编程猫」。

信息顺序固定：品牌名 → 主标题 → 视觉主体 → 支撑点 → 行动入口。不得把二维码放在主标题上方，不得用三行以上小字解释功能。

## 3. 宣传视觉原则

### 3.1 一猫、一树、一代码

- **一猫**：主题猫「小码」是叙事主体，负责情绪和动作；一张主视觉只出现一只猫。
- **一树**：知识树是结构主体，用分支、节点和连线表达「学会了什么、连到哪里」。
- **一代码**：代码纹理只做背景或局部点缀，用低对比等宽字，不使用真实用户代码或密钥。

三者比例建议：主题猫 30%～40%，知识树 30%～40%，留白与文字 30%。猫不压住标题，树不遮住猫脸，代码不抢主信息。

### 3.2 色彩

- 主背景二选一：**墨黑** `#111316`（发布会、开屏、应用商店首图）或**暖纸** `#F7F5EF`（社交媒体、教程、长图）。
- 主强调色：薄荷 `#8CE8C6`；次强调色：珊瑚 `#FF7A66`；柠檬 `#FFD166` 只做奖励点。
- 一张图最多两个强调色；墨黑背景上薄荷可占 20%，暖纸背景上珊瑚不超过 10%。
- 不使用彩虹渐变、霓虹紫、赛博朋克网格和满屏粒子的「AI 感」模板。
- 文字对比度：主标题与背景至少 4.5:1，辅助文字至少 3:1；品牌色不承担长正文。

### 3.3 字体与字阶

| 层级 | 字体 | 建议字号（以 1080px 宽为基准） |
| --- | --- | --- |
| 品牌名 | 得意黑 / Manrope ExtraBold | 96～160px |
| 主标题 | 得意黑 / Manrope Bold | 72～120px |
| 副标题 | Noto Sans SC Medium | 36～52px |
| 支撑标签 | Noto Sans SC Medium | 26～32px |
| 行动入口 | Noto Sans SC Bold | 30～40px |
| 代码纹理 | JetBrains Mono | 18～28px，透明度 10%～18% |

中文标题不超过两行；每行不超过 10 个汉字。英文只做辅助，不与中文主标题等大。

### 3.4 图形语言

- 圆角与猫爪弧线：主卡片 28～40px，标签胶囊，按钮 18～24px。
- 知识树节点使用圆点、胶囊和细线；连线允许轻微发光，但不做粒子爆炸。
- 主题猫允许夸张动作和近景，但保持同一轮廓、同一配色、同一眼睛语言。
- 应用商店截图使用真实界面；概念图必须标注「概念示意」，不得伪装成已上线产品。

## 4. 版式与尺寸

| 渠道 | 画布 | 安全区 | 主标题位置 | 备注 |
| --- | --- | --- | --- | --- |
| 应用商店首图 | 1242×2688 | 四周 8% | 上部 18%～34% | 手机竖屏，顶部留系统裁切 |
| 应用商店横图 | 1920×1080 | 四周 8% | 左侧 42% | 右侧放设备或猫 |
| 小红书封面 | 1080×1440（3:4） | 四周 8% | 上部 15%～35% | 缩略图先看标题 |
| 微信公众号头图 | 1600×680（2.35:1） | 左右 10% | 左侧 55% | 右侧猫脸或树 |
| 发布会 KV | 1920×1080（16:9） | 四周 6% | 中央偏左 | 可加副标题与日期 |
| 开屏 | 1080×1920（9:16） | 顶部 12%、底部 10% | 中部偏上 | 不把 CTA 放底部手势区 |
| 方形社交图 | 1080×1080 | 四周 8% | 上部 20% | 适合微博/社群 |

移动端缩略图测试：把画面缩到 200px 宽，仍能读出品牌名和主标题；读不出就减少元素，不缩小字号。

## 5. 模板规范

### 5.1 应用商店首图

- 顶部：编程猫标识 + 一句主标题「把知识，养成一棵树」。
- 中部：真实手机界面（知识树或学习页）+ 主题猫从侧边探出。
- 底部：三个支撑标签「知识树 / 双语示例 / 安全终端」+ 评分或编辑推荐位（有事实依据时才放）。
- 背景：墨黑，薄荷光只集中在猫与知识树，不铺满全屏。

### 5.2 社交媒体封面

- 暖纸背景，左上品牌名，中央大标题，右下小码招手。
- 标题下只放一句副标题；不在封面塞二维码。
- 3:4 与 1:1 各出一版，猫的脸不能被裁掉。

### 5.3 发布会 KV

- 墨黑背景，左侧品牌名与主张，右侧知识树从猫尾巴生长出来。
- 树的分支用薄荷，节点用暖白，珊瑚只点亮当前节点。
- 底部只放日期、城市/线上信息，不放赞助商矩阵。

### 5.4 开屏

- 品牌名 + 主张 + 小码 + 一个知识节点；2 秒内可读完。
- 不自动跳转广告；跳过按钮在右上角，触控区不小于 48dp。
- 减少动效时静态展示，不做尾巴循环。

### 5.5 分享卡片

- 学习节点标题 + 一句用户可编辑的收获 + 小码 + 品牌名。
- 默认不展示用户笔记全文、搜索历史、AI 对话内容或学习时长。
- 卡片底部放应用名与下载入口，不放诱导分享文案。

## 6. 文案库

### 6.1 主标题

- 把知识，养成一棵树
- 一只猫，陪你把代码读懂
- 从名词到会用，只差一棵树

### 6.2 副标题

- 概念、术语、示例和练习，连成一张可走的图。
- 中英对照，查到就能看懂；看懂就能动手。
- 离线也能学，终端练习有边界，AI 解释有出处。

### 6.3 支撑标签

- 知识树导航
- 中英双语
- 安全终端
- 离线知识包
- AI 拆错
- 进度可回溯

### 6.4 行动入口

- 搜索「编程猫」
- 下载编程猫
- 打开知识树
- 从第一个节点开始

### 6.5 禁用文案

- 三天精通编程
- 零基础年薪百万
- 全网最强 AI
- 取代老师
-  guaranteed / 100% 学会
- 任何贬低用户、制造焦虑或承诺结果的表达

## 7. 图像与插画

| 元素 | 允许 | 禁止 |
| --- | --- | --- |
| 主题猫 | 招手、歪头、抬爪、打盹、尾巴卷成问号 | 写实毛发、恐怖表情、拟人裸体、表情包式夸张 |
| 知识树 | 分支、节点、路径、少量发光 | 无限粒子、3D 旋转迷宫、不可读的密集网络 |
| 代码纹理 | 低对比等宽字、括号、缩进线 | 真实密钥、用户代码、报错全文、仇恨/违法文本 |
| 设备 | 真实 Android 手机边框或中性设备框 | 伪造苹果/谷歌推荐、伪造评分、伪造排名 |
| 人物 | 可选剪影或手部，不抢猫 | 未经授权的真人肖像、儿童特写、虚假用户证言 |

插画交付至少提供：主视觉、无文字版、透明猫、知识树单独层、移动端裁切版。不要把文字直接烧进主视觉；文字应保留可编辑层。

## 8. 宣传动效

### 8.1 6 秒短视频

1. 0～1s：暖纸背景，一颗种子节点落下。
2. 1～2.5s：小码从节点后探头，尾巴画出第一条分支。
3. 2.5～4s：分支长成知识树，节点亮起「概念 → 术语 → 示例 → 练习」。
4. 4～5s：小码抬爪，树冠收束成品牌标识。
5. 5～6s：品牌名 + 主张 + 行动入口。

### 8.2 15 秒版本

在 6 秒结构后增加：真实界面 3 秒（知识树与词典）、安全终端 2 秒、AI 拆错 2 秒、结尾品牌 2 秒。功能画面必须来自真实构建；未上线功能用「概念示意」标注。

### 8.3 动效纪律

- 尾巴、耳朵、眨眼遵守 `tokens.json` 的 240/100/80ms。
- 不做持续漂浮、无限脉冲、自动旋转；不遮挡文字。
- 减少动效版本用静态分镜，不强行加运动。
- 视频导出 1080p，关键帧安全区与海报一致。

## 9. 资产命名与导出

命名格式：

```text
promo-<channel>-<size>-<lang>-<version>.<ext>
```

示例：

```text
promo-appstore-1242x2688-zh-v0.7.0.png
promo-xhs-1080x1440-zh-v0.7.0.png
promo-kv-1920x1080-zh-v0.7.0.png
promo-openscreen-1080x1920-zh-v0.7.0.png
```

导出要求：

- 色彩空间 sRGB；印刷另出 CMYK 校样。
- PNG 用于带透明/文字锐利画面；JPG 质量不低于 90；视频 H.264/H.265。
- 单张 PNG 建议不超过 8MB；应用商店按平台上限压缩。
- 文字转曲前保留可编辑源文件；主视觉保留分层文件。
- 每个渠道至少交付 2× 与 3× 两种密度，或矢量源。

## 10. 审核清单

| 检查 | 通过条件 |
| --- | --- |
| 三秒识别 | 200px 缩略图仍能读出「编程猫」与主标题 |
| 信息层级 | 只有一个主标题、最多三个支撑点、一个行动入口 |
| 品牌一致 | 主题猫、知识树、品牌色与 `09-VISUAL-DESIGN.md` 一致 |
| 色彩纪律 | 最多两个强调色；无彩虹渐变与赛博朋克模板 |
| 字体授权 | 中文展示、正文、代码字体均有商用许可或已购买 |
| 真实声明 | 未上线功能标注概念示意；无伪造评分、排名、推荐 |
| 隐私 | 不出现真实用户笔记、搜索历史、AI 对话、密钥或代码 |
| 可访问性 | 文字对比度达标；开屏跳过按钮不小于 48dp |
| 裁切 | 手机、平板、网页三档裁切后主体不丢失 |
| 文件完整 | 主视觉、无文字版、透明猫、知识树层、各尺寸导出齐全 |

## 11. 命名与法律风险

「编程猫」是编程教育领域已有的品牌名。本文按项目指定名称编写，但在对外发布、应用商店上架、商标注册和广告投放前，必须先完成商标与品牌检索，确认第 9、41、42 类等目标类别不冲突，并取得法律意见。

未完成检索前，建议只在内部文档和设计稿中使用「编程猫」工作名；对外物料使用备选名：

- 码猫 / CodeCat
- 知识猫 / Knowledge Cat
- 码树 / CodeTree

备选名不改变视觉系统，只替换品牌字标；主题猫、色彩、版式和口号可以继续使用。
