同步命令：

```text
python3 scripts/merge_docs.py
python3 scripts/merge_docs.py --check
```

第一条命令生成 `CodeTree-项目文档合集.md`（正文 18 章 + 附录 A 收录 21 份文本工程与设计资产全文）、项目根目录下的 `CodeTree-合并文档包.zip`，并同步一份压缩包到工作区根目录；压缩包另含 5 份 PNG 视觉预览。第二条命令只校验，不写入；除正文锚点、链接、任务编号、约束文本和版本一致性外，还会逐字比对附录文件全文，源文档或资产变更后合集未重生成时会失败。手工编辑合集的内容会在下次生成时被覆盖。

视觉与更新条例校验命令：

```text
python3 scripts/validate_design.py --self-test
python3 scripts/validate_design.py
```

该门禁验证图标三版本、主题猫母版与设定板、渐变令牌、单色镂空、云图结构、5 份 PNG 尺寸、规范页可访问性关键规则和更新条例必备字段。真机视觉、TalkBack 和性能结论必须单独记录。

## 7. MVP（最小可行产品）验收闭环

1. 用户完成首次引导并选择学习方向。
2. 下载或加载一个已签名校验的知识包。
3. 在飞行模式下打开知识树并进入当前路径节点。
4. 查询关联术语，阅读中文解释、英文语法和双语示例。
5. 在终端运行预置安全示例，检查高亮、诊断、输出和取消状态。
6. 主动选择 AI（人工智能）上下文并请求解释，或验证未配置状态。
7. 返回知识节点保存学习进度；全程不依赖账号、社区或完整 Linux。
