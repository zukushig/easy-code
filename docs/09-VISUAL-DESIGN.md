# 09 视觉与美术设计规范（编程猫主题猫）

> 本规范建立「编程猫（CodeCat，仓库代号 CodeTree）」的统一美术语言，覆盖品牌命名、主题猫「小码」、暖纸色界面、知识树云图、动效、可访问性和设计资产验收。设计值以 `design/tokens.json` 为唯一机器可读来源，本文件解释使用规则。

## 1. 品牌命名与设计方向

| 项目 | 决策 |
| --- | --- |
| 中文名 | 编程猫 |
| 英文名 | CodeCat |
| 仓库代号 | CodeTree（仅用于代码、仓库与技术文档，不作为用户可见名称） |
| 品牌角色 | 主题猫「小码」，一只会陪用户拆问题的猫 |
| 品牌主张 | 把知识，养成一棵树 |
| 设计关键词 | 好奇、敏捷、温暖、清晰 |
| 记忆点 | 墨黑猫身、薄荷代码眼、珊瑚耳内、知识枝尾巴、奶油色口鼻 |
| 色彩比例 | 70% 墨黑/暖纸中性色，20% 薄荷，10% 珊瑚与柠檬 |
| 界面语气 | 克制但不说教；有性格，不卖萌；鼓励下一步，不替用户下结论 |
| 明确不做 | 幼稚卡通、写实毛发、表情包轰炸、代码区与终端里的猫耳爪印、持续漂浮动画 |

品牌分两层：**应用图标是印章，主题猫是性格**。图标保持高识别、低细节；主题猫承担引导、空状态、成功/错误和宣传叙事。两者共用同一轮廓语言与品牌色，但不在同一画面争夺注意力。

## 2. 色彩与材质

### 2.1 核心色板

| 语义 | 浅色模式 | 深色模式 | 用途 |
| --- | --- | --- | --- |
| 页面背景 | `#F7F5EF` | `#111316` | 暖纸色最外层页面 |
| 一级表面 | `#FFFDF8` | `#1C1F23` | 卡片、面板、输入区 |
| 二级表面 | `#ECE7DD` | `#2A2E33` | 标签、次级节点、分组背景 |
| 主文字 | `#1B1D21` | `#F7F2E8` | 标题与正文 |
| 次文字 | `#5E625F` | `#B8B2A6` | 补充说明 |
| 边框 | `#D8D0C2` | `#464B52` | 分隔与控件边界 |
| 焦点 | `#2563EB` | `#7DD3FC` | 键盘焦点和当前输入定位 |
| 品牌薄荷 | `#8CE8C6` | `#8CE8C6` | 代码眼、进度、成功高光、宣传主强调 |
| 品牌珊瑚 | `#FF7A66` | `#FF8A76` | 耳内、鼻尖、错误提示辅助、宣传次强调 |
| 品牌柠檬 | `#FFD166` | `#FFD166` | 奖励、收藏、少量高光 |

正文对比度至少 4.5:1，大号文字与图形控件至少 3:1。薄荷与珊瑚不得直接承担长正文或小字号说明；需要文字时使用主文字色，品牌色只做底色、描边、图标和状态辅助。

### 2.2 色彩纪律

- 单页最多使用两个品牌强调色；薄荷为主，珊瑚为辅，柠檬只做点状奖励。
- 渐变只允许出现在应用图标、主题猫尾尖和宣传 KV；普通按钮、卡片、正文和终端使用平面语义色。
- 状态不能只靠颜色：成功带勾选，警告带三角形，错误带错误图标和文字，选中节点带尺寸与描边变化。
- 深色模式不是简单反色：暖纸背景切换为墨黑，薄荷保持品牌识别，珊瑚降低饱和度，终端维持独立深色表面。
- 主题插件只能选择已公开令牌，不能注入渐变、远程图片、任意字体或脚本。

## 3. 主题猫「小码」

### 3.1 性格设定

「小码」不是吉祥物贴纸，而是学习过程中的轻量同伴。它的性格是**好奇、敏捷、敢试错**：

- 遇到新概念会歪头，先观察再拆解。
- 遇到错误不责备，耳朵后压、尾巴打个结，然后指向下一步。
- 完成一个小目标会抬爪庆祝，但不喧宾夺主。
- 不用拟人化说教口吻，不替用户判断「你错了」，只说「这一步可以怎么试」。

### 3.2 造型规则

- 头身比约 `1:1.1`，头部略大，保持幼态但不婴儿化。
- 猫身使用墨黑渐变 `#2A2D33 → #1A1D22 → #111318`；口鼻与爪使用奶油色 `#FFF9EC → #F0E2C9`。
- 耳朵为外深内珊瑚的双层三角；耳内三角决定侧影识别。
- 眼睛为薄荷色杏仁形，瞳孔深墨；也可把瞳孔替换成 `{ }` 或 `<>` 代码括号，但同一画面只选一种。
- 鼻尖为珊瑚色倒三角；嘴部保持简单曲线，不做复杂拟真。
- 尾巴是第二识别点：末端收成一枚薄荷叶片，象征知识树生长；思考时尾巴可卷成问号，打盹时卷成 `@`。
- 颈圈为薄荷色，挂珊瑚圆牌，牌面用 `<>` 镂空；这是「编程」与「猫」的最小连接。
- 轮廓不使用写实毛发、投影贴图或多重高光；矢量平涂为主，允许一层极轻的纸感颗粒。

### 3.3 表情与动作

| 状态 | 姿态 | 使用位置 | 动效 |
| --- | --- | --- | --- |
| 欢迎 | 正坐、尾巴上翘、抬一只前爪 | 首次启动、空首页、品牌页 | 抬爪 160ms，尾巴 240ms，只播一次 |
| 好奇 | 歪头、耳朵前倾、尾巴卷成问号 | 新概念、搜索无结果、引导提示 | 头部 4° 倾斜，80ms 眨眼 |
| 成功 | 双爪抬起、尾尖叶片点亮 | 练习通过、下载完成、连续学习 | 抬爪 160ms，叶片淡入 120ms |
| 出错 | 耳朵后压、尾巴打结、眼神看向下一步按钮 | 错误说明、失败重试、权限拒绝 | 不抖动、不红屏；静态为主，最多 100ms 耳动 |
| 打盹 | 蜷成 `@`、尾巴盖住鼻子 | 长列表空态、夜间模式、加载等待 | 呼吸缩放 2%，周期 4s，可关闭 |
| 加载 | 尾巴缓慢画圈、叶片逐个亮起 | 知识包下载、AI 等待 | 线性循环，减少动效时改为静态三节点 |

表情必须服务于信息，不替代错误原因、按钮文案和进度数字。一个画面只出现一只主题猫；同一屏不叠加两个以上表情动作。

### 3.4 使用边界

- 学习正文、代码块、终端、搜索结果列表不叠加猫耳、爪印、表情或尾巴装饰。
- 主题猫尺寸不超过内容区宽度的 20%；引导页可到 32%，但不得遮挡主标题与主按钮。
- 空状态必须同时给出具体原因和一个主要动作；猫不替代说明。
- 错误状态不嘲笑用户，不使用「又错了」「太笨了」一类文案；猫的表情是中性的、陪伴的。
- 减少动效开启后只保留静态姿态，取消尾巴摆动、呼吸缩放和叶片循环。
- 宣传物中的猫可以更大、更有动作；应用内保持克制，避免把营销表情带进学习界面。

## 4. 字体、间距与形状

| 层级 | 规格 | 使用位置 |
| --- | --- | --- |
| 展示标题 | 34sp，字重 700，字距 -0.02em | 首页、品牌页、宣传主标题 |
| 页面标题 | 28sp，字重 700 | 页面顶部大标题 |
| 区块标题 | 22sp，字重 600 | 分组与节点详情标题 |
| 正文 | 17sp，行高 1.6 | 学习内容与主要说明 |
| 次级说明 | 15sp，行高 1.5 | 元信息、辅助提示 |
| 标签 | 13sp，字重 500 | 状态、关系、分类 |
| 代码 | 14sp，JetBrains Mono | 示例、终端、语法与错误位置 |

- 中文展示字使用得意黑（Smiley Sans，开源）；拉丁展示字使用 Manrope；正文使用 Noto Sans SC / Source Han Sans SC；代码使用 JetBrains Mono。
- 字体不可用时保持字阶、字重、行高与布局，不改变信息层级；不为宣传单独引入未授权字体。
- 间距只允许 4、8、12、16、24、32、48、64dp 序列；宣传版式使用 8pt 网格。
- 圆角升级为「猫爪圆角」：小组件 10dp，按钮 18dp，卡片与面板 28dp，标签胶囊形。
- 触控目标至少 48dp；视觉图形可以更小，但可点击区域不能缩小。
- 中文正文每行建议 28～40 字；代码块横向查看，不通过缩小字号强行塞入。

## 5. 组件与主题猫接入

| 组件 | 统一处理 |
| --- | --- |
| 页面 | 暖纸背景、大标题、分组内容、底部导航共享安全区和 16/24dp 间距 |
| 卡片 | 一级表面、28dp 圆角、细分隔线；阴影只用于浮层和当前浮起对象 |
| 主按钮 | 墨黑底与暖白文字；按下缩放至 0.98 并降低表面亮度 |
| 词典 | 搜索框、术语标签和关联节点使用统一胶囊与分组列表 |
| 终端 | 独立深色表面、等宽字体；高亮颜色沿用语义色，不使用品牌渐变或猫元素 |
| AI 对话 | 用户与助手通过对齐、标签和表面区分，不只更换气泡颜色 |
| 首启引导 | 三段：认识小码、展开知识云图、完成一次练习；猫只做引导，不遮挡真实控件 |
| 空状态 | 单色小码 + 具体原因 + 一个主要动作；猫尺寸不超过内容区 20% |
| 成功状态 | 抬爪小码 + 具体完成项 + 下一步；不使用撒花粒子雨 |
| 错误状态 | 耳朵后压的小码 + 错误原因 + 重试或返回；不使用嘲笑文案 |
| 分享卡片 | 学习节点 + 小码 + 品牌一句话；默认不暴露用户笔记原文 |

所有业务页面调用 `core:designsystem` 的语义令牌。页面内禁止新增局部主题色、重复卡片样式和私有动效时长。

## 6. 知识树：云图扩散

### 6.1 名称与数据边界

「知识树」是产品称谓，底层仍是有向图。云图扩散是布局与交互方式：以当前节点为中心，按图距离和关系类型向外分层展开，同时保留跨域关联、循环检测和稳定内容 ID。

### 6.2 分层结构

| 层级 | 内容 | 默认视觉 |
| --- | --- | --- |
| 中心 | 当前学习节点 | 88dp 深色胶囊，显示名称与当前状态 |
| 第一环 | 直接前置、相关、应用和易混淆节点 | 64dp 一级表面节点，细描边 |
| 第二环 | 从第一环延展的下一层关系 | 52dp 二级表面节点，次级文字 |
| 聚合节点 | 超出当前视口或数量预算的同级关系 | 显示 `+N`，点击后展开该组 |
| 关系边 | 节点之间的语义连接 | 默认 1.25dp；当前路径 2dp；延展关系使用虚线 |

手机首屏默认展示 6 个第一环节点、最多 12 个第二环节点，总可见节点预算为 19。预算只控制默认视觉密度，不截断数据；其余节点通过聚合、筛选和分页式展开访问。

### 6.3 稳定布局算法

1. 以选中节点 ID 为根执行有界广度优先遍历，遍历过程维护 visited 集。
2. 节点按「关系优先级 → 稳定 ID」排序；同层角度使用 `-90° + 360° × index / count`。
3. 第一环半径取短边的 0.26，第二环取 0.43；小屏优先减少同屏数量，不压缩触控目标。
4. 节点重叠时沿各自径向微调，保持原顺序；禁止每次打开使用随机初始位置。
5. 相机回中以选中节点和当前路径为边界，保留至少 24dp 视口边距。
6. 展开、收起和切换节点后，未受影响的节点保持原坐标；返回时恢复缩放、位置和选中状态。
7. 大图使用视口裁剪与分层加载；关系筛选只改变可见集合，不改变原始图数据。

### 6.4 交互与动效

- 点击节点：更新详情预览；再次点击中心或详情按钮进入完整学习页。
- 双指缩放范围 0.65～2.5 倍，支持拖动、双击回中和明确的「回到当前节点」按钮。
- 点击 `+N`：在父节点周围展开该组，聚合节点保留为收起入口。
- 新节点从父节点方向进入，使用透明度与缩放；单节点 280ms，错峰 40ms，总时长不超过 480ms。
- 不使用持续漂浮、粒子爆炸、无限脉冲或自动旋转；这些效果会削弱位置记忆。
- 减少动效开启后取消位移、缩放与错峰，直接呈现最终状态。
- TalkBack 提供等价的节点列表和关系描述，云图不是访问学习内容的唯一方式。

### 6.5 关系识别

| 关系 | 非颜色表达 |
| --- | --- |
| 前置知识 | 实线 + 指向当前节点的箭头 + 「前置」标签 |
| 相关知识 | 实线 + 无箭头 + 「相关」标签 |
| 实际应用 | 实线 + 菱形小标记 + 「应用」标签 |
| 易混淆对比 | 对称双线 + 「对比」标签 |
| 下一层延展 | 虚线 + 「延展」标签 |

默认缩略图隐藏边标签，选中路径和节点详情必须可查看完整关系文本。

## 7. 动效系统

| 场景 | 时长 | 规则 |
| --- | --- | --- |
| 微反馈 | 120ms | 按钮按下、标签切换、焦点移动 |
| 标准转场 | 280ms | 页面内容替换、卡片展开、节点进入 |
| 场景转场 | 560ms | 首启段落、知识云图整体展开 |
| 尾巴摆动 | 240ms | 只播一次或低频循环；减少动效时取消 |
| 眨眼 | 80ms | 随机间隔不短于 6s；不连续闪烁 |
| 耳朵动作 | 100ms | 好奇、出错、听到提示时单次动作 |
| 悬停抬升 | 4dp | 仅桌面/大屏指针设备，触屏不位移 |

- 动效必须解释层级或因果关系，不做无意义装饰。
- 主题猫动作只在状态变化时触发，不随页面滚动持续播放。
- 减少动效开启后取消位移、缩放、循环尾巴与呼吸，保留不超过 120ms 的淡入或直接切换。
- 动效不得阻塞搜索、输入、终端和下载状态反馈。

## 8. 宣传视觉交接

所有宣传物遵循 `docs/11-PROMOTION-DESIGN.md`。宣传可以使用更大的主题猫、更强的对比和品牌色，但必须遵守：

- 一句话主张优先：先看到「编程猫」和「把知识，养成一棵树」，再看到功能点。
- 一张主视觉最多一只主题猫、一棵知识树、一个代码纹理；不堆功能截图。
- 品牌色最多两个强调色；背景使用墨黑或暖纸，不用多彩渐变铺满。
- 应用商店截图必须来自真实界面；概念图不得伪装成实际产品截图。
- 导出前核对安全区、字号、对比度、裁切和移动端缩略图可读性。
