# 09 视觉与美术设计规范

> 本规范建立 CodeTree 的统一美术语言，覆盖「墨猫」品牌图标、苹果式简约界面、知识树云图扩散、动效、可访问性和设计资产验收。设计值以 `design/tokens.json` 为唯一机器可读来源，本文件解释使用规则。

## 1. 设计方向锁定

| 项目 | 决策 |
| --- | --- |
| 目的 | 让编程初学者在低干扰界面中识别当前位置、理解知识关系并完成学习操作 |
| 方向 | 克制、精确、轻量的苹果式简约，不复制苹果专有素材 |
| 品牌主题 | 猫；表达好奇、探索与安静陪伴，不走幼稚卡通路线 |
| 记忆点 | 黑灰渐变圆角底板、银色猫头、由 `<` 与 `>` 组成的代码括号眼睛 |
| 主色 | 石墨黑、雾灰、近白；界面以中性色建立层级 |
| 强调色 | 默认使用石墨色承担主要操作，焦点使用单一功能蓝；错误与成功保留语义色 |
| 字体 | 拉丁展示字 Manrope，中文与正文 Noto Sans SC / Source Han Sans SC，代码 JetBrains Mono |
| 图形语言 | 圆角、细描边、清晰负形、低对比氛围层；禁止无关装饰与多重渐变 |

猫元素集中出现在应用图标、品牌页与空状态。学习正文、代码区和终端不叠加猫耳、爪印或表情，避免主题干扰内容。

## 2. 应用图标：墨猫

### 2.1 构成规则

- 画布为 `1024 × 1024`，主底板四边内缩 32 单位，圆角半径 220。
- 底板采用黑灰对角渐变：`#4B4E53 → #24262A → #0B0C0E`，方向为左上至右下。
- 猫头采用银色渐变：`#FAFAFB → #C7C9CE → #858990`，保留一体式猫耳和圆润脸颊。
- 双眼使用代码括号，鼻口保持简单几何形；小尺寸下优先保留猫耳、脸颊和括号眼睛。
- 图标不使用文字、外发光、写实毛发、彩色眼睛、复杂背景或品牌水印。

### 2.2 资产矩阵

| 文件 | 用途 | 强制验收 |
| --- | --- | --- |
| `design/icons/codetree-icon.svg` | 主图标与商店展示设计母版 | 黑灰渐变、银色猫头和代码眼睛完整 |
| `design/icons/codetree-icon-foreground.svg` | Android Adaptive Icon 前景 | 透明背景；主体处于中央安全区 |
| `design/icons/codetree-icon-mono.svg` | Android Themed Icon 单色层 | 仅使用单一实色与透明镂空，不含渐变 |
| `design/previews/icon-1024.png` | 高分辨率审阅 | 尺寸准确，与主 SVG 一致 |
| `design/previews/icon-192.png` | 常见启动器尺寸审阅 | 轮廓无裁切，括号眼睛清晰 |
| `design/previews/icon-48.png` | 小尺寸辨识审阅 | 仍能辨认猫头与代码眼睛 |

Adaptive Icon 的关键主体落在直径约 66% 的中央安全区内；外圈允许被系统遮罩裁切。单色图标必须使用透明镂空而非白色假镂空，保证系统着色正确。

### 2.3 使用边界

- 图标周围留白至少为图标宽度的 25%，不与标题、边框或其他标识重叠。
- 禁止拉伸、旋转、改变猫耳比例、替换渐变方向或单独给眼睛着色。
- 黑灰渐变属于品牌资产；普通按钮、正文、卡片和终端背景使用平面语义色。
- 空状态可使用单色墨猫，尺寸不超过内容区宽度的 20%，并搭配具体原因与下一步动作。

## 3. 色彩与主题

### 3.1 核心色板

| 语义 | 浅色模式 | 深色模式 | 用途 |
| --- | --- | --- | --- |
| 页面背景 | `#F5F5F7` | `#0B0B0D` | 最外层页面 |
| 一级表面 | `#FFFFFF` | `#1C1C1E` | 卡片、面板、输入区 |
| 二级表面 | `#ECECEF` | `#2C2C2E` | 标签、次级节点、分组背景 |
| 主文字 | `#1D1D1F` | `#F5F5F7` | 标题与正文 |
| 次文字 | `#636366` | `#AEAEB2` | 补充说明 |
| 边框 | `#D2D2D7` | `#48484A` | 分隔与控件边界 |
| 焦点 | `#0A84FF` | `#64D2FF` | 键盘焦点和当前输入定位 |

正文对比度至少 4.5:1，大号文字与图形控件至少 3:1。状态不能只靠颜色：成功带勾选，警告带三角形，错误带错误图标和文字，选中节点带尺寸与描边变化。

### 3.2 深色模式

深色模式不是简单反色。阴影透明度降低，边框对比度适度提高，终端保持独立深色表面；品牌图标原样使用，不随深色模式反相。

## 4. 字体、间距与形状

| 层级 | 规格 | 使用位置 |
| --- | --- | --- |
| 展示标题 | 34sp，字重 700，字距 -0.02em | 首页或品牌页唯一主标题 |
| 页面标题 | 28sp，字重 700 | 页面顶部大标题 |
| 区块标题 | 22sp，字重 600 | 分组与节点详情标题 |
| 正文 | 17sp，行高 1.6 | 学习内容与主要说明 |
| 次级说明 | 15sp，行高 1.5 | 元信息、辅助提示 |
| 标签 | 13sp，字重 500 | 状态、关系、分类 |
| 代码 | 14sp，JetBrains Mono | 示例、终端、语法与错误位置 |

- 中文正文每行建议 28～40 字；代码块按内容横向查看，不通过缩小字号强行塞入。
- 间距只允许使用 4、8、12、16、24、32、48、64dp 序列。
- 小组件圆角 10dp，输入与按钮 16dp，卡片与面板 24dp，标签使用胶囊形。
- 触控目标至少 48dp；视觉图形可以更小，但可点击区域不能缩小。
- 原生 Android 工程需确认字体许可与包体预算；字体不可用时保持字阶、字重和行高，不改变布局规则。

## 5. 组件统一规则

| 组件 | 统一处理 |
| --- | --- |
| 页面 | 大标题、分组内容、底部导航共享安全区和 16/24dp 间距 |
| 卡片 | 一级表面、24dp 圆角、细分隔线；阴影只用于浮层和当前浮起对象 |
| 主按钮 | 石墨底与近白文字；深色模式反转；按下仅缩放至 0.98 并降低表面亮度 |
| 词典 | 搜索框、术语标签和关联节点使用统一胶囊与分组列表 |
| 终端 | 独立深色表面、等宽字体；高亮颜色沿用语义色，不使用彩色品牌渐变 |
| AI 对话 | 用户与助手通过对齐、标签和表面区分，不只更换气泡颜色 |
| 空状态 | 单色墨猫 + 具体原因 + 一个主要动作，插画不替代错误说明 |
| 引导 | 高亮真实控件，单次短说明；遮罩不覆盖目标，提供关闭与重看入口 |

所有业务页面调用 `core:designsystem` 的语义令牌。页面内禁止新增局部主题色、重复卡片样式和私有动效时长。

## 6. 知识树：云图扩散

### 6.1 名称与数据边界

「知识树」是产品称谓，底层仍是有向图。云图扩散是布局与交互方式：以当前节点为中心，按图距离和关系类型向外分层展开，同时保留跨域关联、循环检测和稳定内容 ID。

### 6.2 分层结构

| 层级 | 内容 | 默认视觉 |
| --- | --- | --- |
| 中心 | 当前学习节点 | 88dp 深色胶囊，显示名称与当前状态 |
| 第一环 | 直接前置、相关、应用和易混淆节点 | 64dp 一级表面节点，细描边 |
| 第二环 | 从第一环延展的下一层关系 | 52dp 二级表面节点，次级文字 |
| 聚合节点 | 超出当前视口或数量预算的同级关系 | 显示 `+N`，点击后展开该组 |
| 关系边 | 节点之间的语义连接 | 默认 1.25dp；当前路径 2dp；延展关系使用虚线 |

手机首屏默认展示 6 个第一环节点、最多 12 个第二环节点，总可见节点预算为 19。预算只控制默认视觉密度，不截断数据；其余节点通过聚合、筛选和分页式展开访问。

### 6.3 稳定布局算法

1. 以选中节点 ID 为根执行有界广度优先遍历，遍历过程维护 visited 集。
2. 节点按「关系优先级 → 稳定 ID」排序；同层角度使用 `-90° + 360° × index / count`。
3. 第一环半径取短边的 0.26，第二环取 0.43；小屏优先减少同屏数量，不压缩触控目标。
4. 节点重叠时沿各自径向微调，保持原顺序；禁止每次打开使用随机初始位置。
5. 相机回中以选中节点和当前路径为边界，保留至少 24dp 视口边距。
6. 展开、收起和切换节点后，未受影响的节点保持原坐标；返回时恢复缩放、位置和选中状态。
7. 大图使用视口裁剪与分层加载；关系筛选只改变可见集合，不改变原始图数据。

### 6.4 交互与动效

- 点击节点：更新详情预览；再次点击中心或详情按钮进入完整学习页。
- 双指缩放范围 0.65～2.5 倍，支持拖动、双击回中和明确的「回到当前节点」按钮。
- 点击 `+N`：在父节点周围展开该组，聚合节点保留为收起入口。
- 新节点从父节点方向进入，使用透明度与缩放；单节点 320ms，错峰 40ms，总时长不超过 480ms。
- 不使用持续漂浮、粒子爆炸、无限脉冲或自动旋转；这些效果会削弱位置记忆。
- 减少动效开启后取消位移、缩放与错峰，使用不超过 120ms 的淡入，或直接呈现最终状态。
- TalkBack 提供等价的节点列表和关系描述，云图不是访问学习内容的唯一方式。

### 6.5 关系识别

| 关系 | 非颜色表达 |
| --- | --- |
| 前置知识 | 实线 + 指向当前节点的箭头 + 「前置」标签 |
| 相关知识 | 实线 + 无箭头 + 「相关」标签 |
| 实际应用 | 实线 + 菱形小标记 + 「应用」标签 |
| 易混淆对比 | 对称双线 + 「对比」标签 |
| 下一层延展 | 虚线 + 「延展」标签 |

默认缩略图隐藏边标签，选中路径和节点详情必须可查看完整关系文本。

## 7. 引导与品牌动效

首次启动可采用三段短引导：认识墨猫、展开知识云图、完成一次练习。图标只允许一次 160ms 的轻微缩放反馈；云图用一次分层展开说明关系；最后直接进入可选择的学习方向。

引导不使用自动轮播。跳过后立即进入主界面，设置中保留重看入口。所有动效遵循系统减少动效设置，且不得阻塞搜索、输入、终端和下载状态反馈。

## 8. 设计资产与实现交接

每次视觉交付至少包含：设计方向、令牌变更、源 SVG、适用 PNG、深色/浅色预览、小尺寸预览、减少动效说明、可访问性检查、变更记录和验证结果。

- 矢量母版保存在 `design/`，禁止把截图作为图标源文件。
- 业务模块引用语义令牌，禁止复制 `tokens.json` 形成第二份色板。
- 主题插件只能选择已公开令牌，不能注入渐变、远程图片、任意字体或脚本。
- 图标、云图和通用组件的变更同时遵循 `docs/10-UPDATE-POLICY.md`。

## 9. 美术验收清单

| 关卡 | 通过条件 |
| --- | --- |
| 品牌识别 | 48px 预览仍能识别猫耳、脸颊与代码括号眼睛 |
| 图标一致 | 主图标、自适应前景、单色层来自同一轮廓，无比例漂移 |
| 渐变纪律 | 渐变只出现在指定品牌资产；界面组件使用语义色 |
| 字体统一 | 展示、中文正文和代码字体职责明确，字号与行高来自令牌 |
| 云图稳定 | 同一数据与选中状态重复进入时布局一致，返回位置可恢复 |
| 云图可读 | 默认密度不超预算，重叠与溢出可处理，关系不只靠颜色 |
| 动效克制 | 无持续装饰动画；减少动效下无强制位移和缩放 |
| 可访问性 | 48dp 触控、对比度、焦点、TalkBack 等价列表和字体缩放通过 |
| 资产完整 | SVG、PNG、令牌、规范、变更记录和校验结果均可追踪 |
